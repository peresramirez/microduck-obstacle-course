# E1 build scripts

Everything needed to rebuild E1 (gentle hump) from nothing, exactly as the files in `../` were made.

## Rebuild

1. Open **FreeCAD 1.1.x** (the FreeCAD MCP add-on starts its RPC server on port 9875 by itself) and **Blender 5.2.x** (N-panel → *MCP for Blender* → *Connect*, port 9876). Setup: `../../../../SETUP.md` sections 5–6.
2. From `isaac-obstacle-course/`:

```bash
assets/E1-gentle-hump/build/build.sh                                   # overwrites assets/E1-gentle-hump/
OUT=/tmp/e1 DOC=E1_test SCENE=E1_test assets/E1-gentle-hump/build/build.sh   # somewhere else, other names
RECORD=02-1-e1-clean-build assets/E1-gentle-hump/build/build.sh        # also records videos/<RECORD>-{freecad,blender}.mp4
```

It takes about 1 minute (2 with `RECORD`), costs nothing and ends with `tools/check_asset.py` (11 checks).

Verified 2026-10-26: a rebuild into a scratch folder gave the same STEP geometry (only the header timestamp differs), a pixel-identical preview (SSIM 1.000) and the same 11/11 checks. The files in `../` were then regenerated by `build.sh` itself.

## What runs, in order

| Step | Script | App | Does |
|---|---|---|---|
| 1 | `freecad/01_params.py` | FreeCAD | New document, `Params` spreadsheet: `length` 1000 mm, `width` 600 mm, `crest` 33 mm |
| 2 | `freecad/02_profile.py` | FreeCAD | PartDesign body + `Profile` sketch on XZ: 32-segment cosine polyline, every vertex bound to `Params` (98 constraints, fully constrained) |
| 3 | `freecad/03_pad.py` | FreeCAD | `Hump` pad, symmetric, `Length = Params.width` |
| 3b | `freecad/03b_demo_crest.py` | FreeCAD | On-camera demo: crest 44 → 10 → 33 mm (back to spec) |
| 4 | `freecad/04_export.py` | FreeCAD | Saves `model.FCStd`, exports `model.step` and `freecad-mesh.stl`, reads the STEP back |
| — | `../../_materials/birch-plywood/make_texture.py` | Blender | Only if `basecolor.png` is missing: generates the plywood texture (seed 11) |
| 5 | `blender/01_import.py` | Blender | New scene, imports the STL at 0.001, bakes the scale into the vertices |
| 6 | `blender/02_material.py` | Blender | UVs in metres, `BirchPlywood` material |
| 7 | `blender/03_stage.py` | Blender | Preview-only collection: floor, 25 cm marker + label, sun, camera |
| 8 | `blender/04_render.py` | Blender | `preview.png` (Eevee 1920×1080) |
| 9 | `blender/05_export.py` | Blender | `model.usd` (+ `textures/`), `model.glb`, `model.blend` |

`blender/_common.py` is sent in front of every Blender step (window, viewport, context override, lookup by a `role` property).

The scripts take their names and paths as variables (`DOC`, `SCENE`, `OUT`, `TEX`, `CREST`), set by `tools/apps.py exec … --var NAME=VALUE`. To run one step by hand:

```bash
uv run --no-project python tools/apps.py exec freecad assets/E1-gentle-hump/build/freecad/03_pad.py --var DOC=E1_gentle_hump
uv run --no-project python tools/apps.py exec blender assets/E1-gentle-hump/build/blender/_common.py assets/E1-gentle-hump/build/blender/04_render.py --var SCENE=E1_gentle_hump --var OUT=$PWD/assets/E1-gentle-hump
```
